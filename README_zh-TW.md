# FunctionCallReverseTool

繁體中文 | [English](README.md)

歡迎使用 **FunctionCallReverseTool**，這是一款專為資安研究人員和逆向工程師設計的多功能工具。本工具能夠高效地從二進位檔案中提取函數呼叫和呼叫圖，提供程式行為和控制流程的關鍵見解。它相容三個領先的逆向工程平台：IDA Pro、Ghidra 和 Radare2。無論您是從事二進位分析、惡意軟體研究，還是網路安全教育，**FunctionCallReverseTool** 都能透過利用各平台的獨特功能來適應您的環境：

- **[IDA Pro](https://www.hex-rays.com/products/ida/)**：以其全面的反組譯能力而聞名，IDA Pro 允許進行深入的分析和互動式除錯。
- **[Ghidra](https://ghidra-sre.org/)**：由美國國家安全局開發，Ghidra 提供強大的反編譯和腳本功能，非常適合協作分析。
- **[Radare2](https://www.radare.org/n/)**：一款免費且開源的工具，Radare2 非常適合需要高度可自訂框架的使用者，支援多種架構和二進位格式。

透過 **FunctionCallReverseTool**，您可以簡化逆向工程流程、提高分析效率，並透過精確的函數呼叫提取深入了解可執行檔。探索逆向工程的力量，這款工具專為滿足專業人士和愛好者的需求而打造。
